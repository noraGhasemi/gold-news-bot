# ربات خبر طلا (تلگرام)

هر ۳۰ دقیقه اجرا می‌شود، روی GitHub Actions، بدون سرور و بدون IP پابلیک.

## چه کار می‌کند

| بخش | منبع | چه می‌فرستد |
|---|---|---|
| خلاصه‌ی روزانه | تقویم MetalsMine | هر روز حدود ۸ صبح تالین: ایونت‌های High و Medium امروز با توضیح فارسی |
| هشدار ایونت | تقویم MetalsMine | بین ۱۵ تا ۴۵ دقیقه قبل از هر ایونت High/Medium (به خاطر تأخیر GitHub ممکن است دیرتر برسد) |
| خبر | صفحه‌ی خبر MetalsMine | فقط خبرهای مرتبط با طلا با اهمیت High/Medium: تیتر، ساعت تالین، خلاصه، اثر روی طلا، ترجمه، لینک |

- اهمیت ایونت‌ها را خود سایت تعیین می‌کند.
- اهمیت خبرها: اگر سایت به خبر رتبه داده باشد همان استفاده می‌شود؛ وگرنه Gemini تخمین می‌زند و در پیام نوشته می‌شود «تخمین هوش مصنوعی».
- ترجمه فقط از متنی است که MetalsMine منتشر می‌کند (معمولاً چند خط اول مقاله)، نه کل مقاله در سایت اصلی.

## راه‌اندازی (یک بار، حدود ۲۰ دقیقه)

### ۱. ربات تلگرام
1. در تلگرام به `@BotFather` پیام بده، بنویس `/newbot`، اسم و یوزرنیم بده.
2. توکنی که می‌دهد را نگه دار (شبیه `123456:ABC-...`).

### ۲. کانال
1. کانال را بساز.
2. ربات را به‌عنوان **ادمین** با دسترسی **Post Messages** اضافه کن.
3. شناسه‌ی کانال (Chat ID):
   - اگر کانال عمومی است: `@username` کانال.
   - اگر خصوصی است: یک پیام در کانال بفرست، بعد در مرورگر باز کن:
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
     و عددی را که با `-100` شروع می‌شود (در `"chat":{"id": ...}`) بردار.

### ۳. کلید Gemini
در aistudio.google.com یک کلید API در **پروژه‌ی جدید** (نه پروژه‌ی اکستنشن) بساز.
نام مدلی که در اکستنشنت کار می‌کند را هم یادداشت کن (مثلاً `gemini-2.5-flash`).

### ۴. گیت‌هاب
1. یک ریپوی جدید **Public** بساز، مثلاً `gold-news-bot`.
   (Public یعنی دقیقه‌های Actions نامحدود و رایگان است. کد و state.json دیده می‌شوند، ولی کلیدها مخفی می‌مانند.
   ریپوی Private با اجرای هر ۱۵ دقیقه از سهمیه‌ی رایگان ماهانه بیشتر مصرف می‌کند.)
2. **Add file → Upload files**: فایل‌های `bot.py`، `requirements.txt`، `state.json` را آپلود کن.
3. **Add file → Create new file**: در کادر نام بنویس `.github/workflows/news.yml` و محتوای فایل `news.yml` را paste کن. Commit.
   (پوشه‌ی `.github` در Finder مک مخفی است، برای همین این‌طوری می‌سازیمش.)

### ۵. کلیدها در گیت‌هاب
**Settings → Secrets and variables → Actions**

تب **Secrets** → New repository secret، سه تا:
- `TELEGRAM_BOT_TOKEN` = توکن ربات
- `TELEGRAM_CHAT_ID` = شناسه‌ی کانال
- `GEMINI_API_KEY` = کلید Gemini

تب **Variables** → New repository variable:
- `GEMINI_MODEL` = نام مدل (اگر نگذاری، `gemini-2.5-flash` استفاده می‌شود؛ ممکن است این مدل دیگر موجود نباشد)

### ۶. اجرای اول
**Actions** → اگر خواست، فعالش کن → `gold-news-bot` → **Run workflow**.

اجرای اول:
- پیام «✅ ربات خبر طلا فعال شد» در کانال می‌آید.
- خبرهای فعلی سایت فقط «دیده‌شده» علامت می‌خورند و ارسال نمی‌شوند (تا کانال پر نشود). خبرهای جدید از اجرای بعد می‌آیند.

## عیب‌یابی

| مشکل | علت محتمل |
|---|---|
| پیام فعال‌شدن نیامد | توکن یا Chat ID غلط است، یا ربات ادمین کانال نیست. لاگ Actions را ببین. |
| خطای 403 برای metalsmine.com در لاگ | سایت درخواست‌های سرورهای GitHub را بلاک کرده. راه‌حل: اجرا روی مک یا یک VPS ارزان. |
| خطای Gemini 404 | نام مدل غلط است؛ `GEMINI_MODEL` را درست کن. |
| خطای Gemini 429 | سهمیه‌ی رایگان تمام شده؛ ربات دفعه‌ی بعد دوباره تلاش می‌کند. |
| «no news items were found» | طراحی صفحه‌ی سایت عوض شده و parser باید اصلاح شود. |

اگر یکی از منبع‌ها ۸ بار پشت سر هم (حدود ۴ ساعت) خطا بدهد، ربات یک هشدار در کانال می‌فرستد.

## تنظیمات (بالای bot.py)

- `EVENT_IMPACTS` / `NEWS_IMPORTANCE`: سطح‌های اهمیت ارسالی
- `DAILY_BRIEF_HOUR`: ساعت خلاصه‌ی روزانه
- `ALERT_LEAD_MINUTES`: چند دقیقه قبل از ایونت هشدار بدهد
- `EXCLUDE_EVENT_WORDS`: ایونت‌های غیرطلایی که حذف می‌شوند (مس، آلومینیوم و...)

## تست روی مک (اختیاری)

```bash
pip3 install -r requirements.txt
DRY_RUN=1 GEMINI_API_KEY=... python3 bot.py
```
با `DRY_RUN=1` پیام‌ها فقط در ترمینال چاپ می‌شوند.
